# Google Classroom Integration Feature

This folder contains Google OAuth, API hooks, and parsing utilities to fetch coursework, announcements, and timetables.

## Planned Sub-components:
- `ClassroomSyncButton.jsx`: Connects to Google Classroom account.
- `ImportCoursesList.jsx`: List of imported courses and sync statuses.
- `FeedAggregator.jsx`: Consolidated feed of files and announcements.
